A deadpan one-star review, in a single line of at most 160 characters, of an everyday essential everyone relies on. `main.py` (stdlib only, deterministic) writes that one line to `entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

Run it with:

```sh
python3 main.py
```
